# 学习论坛

这里是《Agent Harness 手册》的站内社区。手册负责把知识讲清楚，论坛负责解决知识到不了的地方——你卡住的那一步、你走过的弯路、你想看的主题。

## 版块

| 版块 | 干什么用 |
| --- | --- |
| [求助问答](/community/qa) | 学习或动手时卡住了，来这里问。好问题自带上下文 |
| [学习打卡](/community/checkin) | 配合[学习路径](/guide/paths)记录进度，互相督促走完三条路线 |
| [经验分享](/community/share) | 转行经验、面试复盘、作品集项目秀——你的路径可能正是别人缺的地图 |
| [内容许愿池](/community/wishes) | 想让手册讲什么主题？在这里许愿，需求多的优先写 |

## 规则（就三条）

1. **对事不对人。** 没有愚蠢的问题，只有没写清楚的问题。
2. **提问带上上下文。** 你在哪一页、哪一步、看到什么现象/报错——照着这个格式问，得到答案的速度快一倍。
3. **不发广告、不灌水、不转载侵权内容。** 违规内容会被删除。

## 提问模板（求助问答版）

```text
【我在哪】页面/教程名 + 具体小节（贴链接最好）
【我想做什么】一句话目标
【发生了什么】报错原文 / 实际现象
【我试过什么】已经尝试的排查
```

## 微信群

扫码加站主微信，备注「harness」，拉你进学习群。群里做即时讨论和更新通知；问题和答案还是建议发在论坛里，方便沉淀和被搜索到。

<img src="/wechat-qr.png" alt="微信群二维码" width="220" />

::: tip 为什么论坛开在站内而不是微信群？
微信群的讨论三天就沉底，无法搜索、无法沉淀；论坛里的每个问题和答案会一直留在这里，被后来的读者搜到。微信群适合做即时闲聊和通知，论坛适合做知识沉淀——两者互补，不是替代。
:::
